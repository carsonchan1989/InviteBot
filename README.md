# 美容师邀约话术生成器

## 项目概述

这是一款针对养生美容院的微信小程序，帮助美容师快速生成客户邀约话术。美容师通过输入邀约信息，结合预设提示词，调用AI大模型API生成专业邀约话术，提高邀约效率和专业度。

## 主要功能

- **话术生成**：输入邀约对象、日期、理由和项目，快速生成专业邀约话术
- **用户管理**：微信授权登录，区分管理员和美容师角色
- **后台管理**：管理用户权限、使用次数限制与统计、店内项目管理
- **数据存储**：保存美容养生项目数据、用户使用记录和生成话术历史
- **品牌宣传**：结果页面底部展示品牌信息、联系方式和服务理念
- **个人资料**：支持用户自定义头像和昵称，提升用户体验

## 技术架构

- **前端**：微信小程序（WXML/WXSS/JS）
- **后端**：微信云开发（云函数、云数据库）
- **AI接口**：接入AI大模型API（支持腾讯混元、DeepSeek等）

## 项目结构

```
- miniprogram/
  - pages/
    - index/ (邀约信息输入页)
    - result/ (话术生成结果页)
    - login/ (登录页)
    - admin/ (管理员后台)
    - profile/ (个人资料编辑)
  - components/ (公共组件)
  - utils/ (工具函数)
  - services/ (API服务)
  - styles/ (公共样式)
  - images/ (图片资源)
- cloudfunctions/
  - login/ (用户登录)
  - generateScript/ (生成话术)
  - getUser/ (获取用户信息)
  - updateUserProfile/ (更新用户资料)
  - checkUser/ (检查用户是否已注册)
  - manageUsers/ (用户管理)
  - manageProjects/ (项目管理)
```

## 性能优化内容

1. **话术生成机制优化**：
   - 优化云函数API调用超时设置，从30秒增加到60秒
   - 调整流式响应超时时间至180秒，提高大模型响应成功率
   - 前端采用渐进式轮询策略：首次45秒，第二次25秒，第三次15秒，之后每5秒
   - 优化用户界面提示，提供更清晰的生成状态反馈

2. **头像显示问题修复**：

## 安装与使用

1. 克隆项目代码
2. 在微信开发者工具中导入项目
3. 配置云开发环境（修改 app.js 中的环境 ID）
4. 部署云函数
5. 创建数据库集合：users、projects、histories
6. 开始使用
